PROTOCOLE HTTP

Hyper Text Transfer Protocol Transfert de fichier du type page HTML (navigation web)
Serveur web HTTP : port 80
Serveur web HTTPS : port 443

PROTOCOLE FTP

File Transfer Protocol
Transfert de fichier
Serveur FTP : port 21

PROXY

- Filtrage (Pare Feu)
- Gestion de White List et Black List
- Mise en cache (économie de bande passante)
- Journalisation (Sauvegarde des Logs)
- Gestion des horaires d'accès à Internet

Adresses IP Privées

Adresses non routables sur Internet
Utilisation du NAT pour translater les adresses privées en publiques
10.0.0.0 à 10.255.255.255
172.16.0.0 à 172.31.255.255
192.168.0.0 à 192.168.255.255

PROTOCOLE SMTP

Simple Mail Transfer Protocol
Transfert de courrier électronique
Serveur mail SMTP : port 25

PROTOCOLE POP

Post Office Protocol
Récupération de courrier électronique auprès d'un serveur de messagerie


PROTOCOLE IMAP


Internet Message Access Protocol
Accès au courrier électronique stocké sur un serveur de messagerie

PROTOCOLE DNS

Domain Name System
Etablit la correspondance entre un nom d'hote et une adresse IP
Serveur DNS : port 53

PROTOCOLE DHCP

Dynamic Host Configuration Protocol
Distribution automatique d'adresses IP, masque, passerelle, DNS
Serveur DHCP : port 67

PROTOCOLE NTP

Network Time Protocol
Synchronisation via un réseau d'horloge système
Serveur NTP : port 123

PROTOCOLE SNMP

Simple Network Management Protocol
Administration à distance et supervision d'équipements ou de logiciels

Haute Disponibilité

La Haute Disponibilité (High Availibility) basée sur la répartition de charge (Load Balancing) et la redondance (Failover) permet de garantir la continuité de service
(éviter au maximum les indisponibilités)


SSH (Secure SHell)

Protocole de communication sécurisé (échange de clés de chiffrement afin de crypter les communications)


DRBD (Distributed Replicated Block Device)

Outil permettant de synchroniser (par réplication) des périphériques de stockage (disque dur, partition) entre deux serveurs via le réseau
(DRBD s'apparente à du RAID1 sur IP)


NAS (Network Attached Storage

Un serveur NAS est un serveur de stockage connecté sur un switch au réseau LAN.



SAN (Storage Area Network)

Un SAN est un réseau de stockage séparé du réseau LAN.
Les serveurs connectés au SAN possèdent une carte réseau connectée au LAN et une carte réseau connectée au SAN.

-> Amélioration de la bande passante.

PRA (Plan de Reprise d'Activité)

Le PRA est une analyse des ressources et des moyens à mettre en œuvre pour poursuivre l’activité d’une entreprise en cas de sinistre
(données, systèmes moyens techniques et humains).


HSRP (Host Standby Router Protocol

Hot Standby Router Protocol (HSRP) est un protocole propriétaire de Cisco implémenté sur les routeurs et les commutateurs de niveau 3 permettant une continuité de service. HSRP est principalement utilisé pour assurer la disponibilité de la passerelle par défaut dans un réseau en dépit d'une panne d'un routeur (mise en place d'une adresse IP virtuelle).

Protocole 802.1d (Spanning Tree)

Le Spanning Tree Protocol (aussi appelé STP) est un protocole réseau de niveau 2 permettant de construire un réseau sans boucle dans un LAN avec redondance de liaisons entre les switchs. Il évite ainsi les tempêtes de diffusion (tempêtes de broadcast).


Fibre optique

Support de transmission basé sur deux brins (emission et réception) transportant de la lumière
Débit équivalent ou supérieur à 1 Gbits/s

Câble Cuivre

Support de transmission basé sur deux paires torsadées
Débits : 100 Mbits/sec à 10 Gbits/sec

Quality Of Service (QoS)

capacité à fournir un service conforme à des exigences en matière de temps de réponse et de bande passante.
Priorisation des flux afin de garantir un débit


VPN (Virtual Private Network)

Technologie permettant de créer une connexion sécurisée entre deux sites distants en utilisant le réseau public Internet


ADSL/SDSL Asymetric/Symetric Digital Subscribe Line

Technologie permettant de transmettre sur une ligne téléphonique des informations analogiques à haut débit
La transformation des informations en numérique nécéssite un modem (modulateur/démodulateur), fonction effectuée par le routeur


Agent relais DHCP

Service offert par un routeur permettant de relayer les demandes DHCP sur des réseaux différents de celui du serveur DHCP.

Le serveur DHCP doit posséder plusieurs étendues, une dans chaque réseau où le service Agent Relais DHCP est accessible par les postes.

NAT / PAT

NAT : Network Address Translation (translation adresse IP publique Internet vers adresse IP privée LAN
PAT : Port Address Translation (translation d'un port ouvert sur Internet vers un port ouvert situé sur un serveur sur un LAN.


RAID (Redundant Array Independant Disk)

Technologie permettant d'associer plusieurs disques durs afin d'augmenter la sécurité des données et les taux de transfert (lecture/écriture)
RAID 0 : amélioration des performances en lecture / écriture
RAID 1 : disques en mirroir (réplication)
RAID 5 : sécurisation des données et performances augmentées


Possibilité de combiner les niveaux de RAID

Protocole 802.1Q

Ce protocole permet de taguer les trames afin de transporter l'identificateur (numéro) du VLAN sur le réseau (entre deux switchs).
Un lien TRUNK est un lien entre deux switchs qui permet de faire transiter le numéro de VLAN afin de faire communiquer des postes situés sur le même VLAN.
